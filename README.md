# Проект: Аналитическая платформа интернет-магазина

### О проекте

Это консольная аналитическая платформа, которая работает с тремя связанными наборами данных: заказами, каталогом товаров и базой покупателей. Платформа готовит и загружает данные из CSV-файлов, отбраковывает некорректные записи с ведением журнала, объединяет источники по ключу, считает аналитику двумя способами (на чистом Python и средствами Pandas), находит аномальные заказы и формирует итоговый отчет с экспортом в JSON и CSV. Проект создавался как финальная работа курса по Python с целью собрать в один конвейер обработки данных материал всех трех модулей.

### Используемые технологии

* Python 3 (функции, словари, множества, кортежи, исключения)
* Модули `csv` и `json`
* NumPy (статистика и поиск аномалий через логическую индексацию)
* Pandas (DataFrame, сводные таблицы, `groupby`)

### Что умеет платформа

1. Подготовка файлов `customers.csv`, `products.csv`, `orders.csv`
2. Загрузка каталогов в словари по идентификатору
3. Валидация заказов, журнал отбраковки `rejected.csv`
4. Объединение заказов с товарами и покупателями
5. Нормализация текстовых полей
6. Аналитика на чистом Python: выручка по разрезам, топ покупателей и товаров
7. Статистика и аномальные заказы средствами NumPy
8. Многомерный анализ средствами Pandas
9. Итоговый отчет и экспорт в JSON и CSV
10. Интерактивная консоль с меню

### Структура проекта

* `index.py` — весь код проекта, разбитый на этапы
* `customers.csv`, `products.csv`, `orders.csv` — исходные данные (создаются программой)
* `rejected.csv` — журнал отбракованных заказов
* `full_report.json`, `category_revenue.csv`, `segment_revenue.csv`, `city_revenue.csv` — отчеты, создаются через пункт меню «Сохранить отчеты в файлы»
* `requirements.txt` — зависимости

### Для запуска проекта
1. Клонируйте репозиторий и перейдите в папку проекта
2. Создайте виртуальное окружение командой `python3 -m venv .venv` и активируйте его командой `source .venv/bin/activate`
3. Установите зависимости командой `pip install -r requirements.txt`
4. Запустите проект командой `python index.py`
